## 最容易记错的几句话

- 极限看函数值趋向哪里；导数看差商趋向哪里。
- 可导一定连续；连续不一定可导。
- 左右极限相等，只解决双侧极限是否存在；还不能保证连续或可导。
- 端点按定义域和课件的单侧导数约定处理。
- 分母为零只给竖直渐近线的候选位置，约分后可能只是一个空点。
- 复合求导要保留内层，再乘内层导数；求时间变化率要看清 $dx/dt$。
- 线性近似用中心处的 $f'(a)$；$dy$ 估计变化量，新值还要加回 $f(a)$。
- 临界点只是极值的候选位置；闭区间求绝对极值还要比较端点。
- 等价替换遇到相减先检查主项是否抵消；洛必达每用一次都检查条件。

## 最容易记错的几句话

- 极限看函数值趋向哪里；导数看差商趋向哪里。
- 可导一定连续；连续不一定可导。
- 左右极限相等不能推出左右导数相等。
- 端点按定义域和课件的单侧导数约定处理，不能一概说不可导。
- 对 x 求导可以求出相对 x 的变化率；求相对时间的变化率还需要链式法则。
- 临界点是候选位置；内部极值点只有在可导时才必须满足导数为零。

# 后续问题：临界点、极值与多项式零点

[返回目录](../README.md)

保留此前问过的 critical point、extrema、导数不存在、cubic polynomial 与零点关系；省略具体题解。

## 1. Critical point 到底是什么？

按 Week 4 第 38 页的定义：**函数定义域的内部点 c，若 f'(c)=0 或 f'(c) 不存在，就是临界点。**

临界数是横坐标 c；对应图像上的点是 (c,f(c))。口语里常混称，写答案时应说明所给的是位置还是函数值。

步骤：先看原函数定义域 → 在可求导处求 f' → 解 f'=0 → 查其他不可导位置 → 核对是否为定义域内部点。端点按本课件定义单列，不混入内部临界点。

## 2. 怎么发现“导数不存在”的位置？

| 线索 | 要进一步检查什么？ |
| --- | --- |
| 分段函数连接点 | 连续性与左右差商 |
| 绝对值改变表达式的位置 | 是否有尖角，或是否恰好仍可导 |
| 根式、分母等使导数公式失效 | 原函数是否有定义，差商是否有有限极限 |
| 图像的尖点、垂直切线或振荡 | 差商极限的实际行为 |

公式在某处不能代入，只是需要检查的信号，不能替代定义。特别是原函数在那里没有定义，就不是原函数的临界点。例如 1/x 在 0 没定义，所以 0 不是它的临界点。

## 3. Local extrema 一定满足 f'=0 吗？

正确命题带有两个前提：c 是**内部局部极值点**，并且 **f'(c) 存在**，才能推出：

$$
f'(c)=0.
$$

这就是 Fermat 定理（课件称 First Derivative Theorem for Local Extreme Values）。

| 情况 | 最小例子 | 结论 |
| --- | --- | --- |
| 内部极值但不可导 | $\lvert x\rvert$ 在 0 | 有局部最小值，导数不存在 |
| 导数为零但没有极值 | x³ 在 0 | 临界点不保证极值 |
| 闭区间端点有绝对极值 | x 在 [0,1] | 端点极值不要求导数为零 |

因此不能把定理倒过来用，也不能删掉“内部”“可导”两个条件。

## 4. Local、absolute、端点，分别怎么判断？

- local maximum/minimum：只与定义域中足够近的点比较。
- absolute maximum/minimum：与所讨论集合中的全部点比较。
- 极值点给位置；极值给函数值。例如“在 c 处取得最小值 f(c)”同时说明了两者。

Week 4 第 35 页的局部极值定义按“定义域内附近的点”比较。在这种定义下，端点也可能具有相对于定义域的单侧局部极值。课程或题目若专指内部局部极值，则按题目约定处理；**端点不要求导数为零，也始终要作为闭区间绝对极值的候选位置。**

## 5. 一阶导数检验需要什么条件？

课件的检验用于在 c 连续、且 c 两侧邻近处可导的函数；c 自身可以不可导。在这些条件下观察两侧 f' 的符号：

| 左侧 → 右侧 | 函数变化 | 结论 |
| --- | --- | --- |
| 正 → 负 | 先增后减 | 局部极大 |
| 负 → 正 | 先减后增 | 局部极小 |
| 两侧均正或两侧均负 | 保持同一单调方向 | 不是局部极值 |

这里的“不变号”指两侧始终严格同为正或同为负。若导数在邻域恒为零，例如常数函数，不能套成“没有极值”；按非严格定义，它每一点都是局部最大值点和最小值点。

若 c 不连续，不能仅凭左右导数变号套这张表，应按函数值直接检查局部极值定义。

## 6. 闭区间求绝对极值，为什么必须看端点？

连续函数在有限闭区间 [a,b] 上一定取得最大、最小值。按闭区间法：

1. 找区间内部的所有临界点；
2. 计算这些点以及 a、b 的函数值；
3. 比较函数值，给出最大、最小值及取得的位置。

要比较的是 f(c)、f(a)、f(b)，不是导数值。若区间不闭、不有界或函数不连续，不能直接引用这个存在性保证，需要另行检查。

## 7. Cubic polynomial 与“求导降次”

三次多项式是 ax³+bx²+cx+d，a≠0。求导后最高项变成 3ax²，所以次数从 3 降为 2；这是求导降次，不是把原方程两边平方或开根号。

非零 n 次多项式最多有 n 个不同实零点。因此三次多项式最多有 3 个不同实零点，其导数最多有 2 个不同实零点。“最多”不等于“一定”；三次多项式可以只有 1 个不同实零点。重根的重数与不同零点的个数要分清。

## 8. 函数零点与导数零点为什么有关？

Rolle 定理要求：在 [a,b] 连续，在 (a,b) 可导，且 f(a)=f(b)。结论是某个 c∈(a,b) 满足 f'(c)=0。端点只要求连续，不要求可导。

若两个不同点都是多项式零点，端点函数值都为 0，且多项式自动满足连续、可导条件；因此它们之间至少有一个导数零点。

三次多项式若有 3 个不同实零点，则两个相邻零点之间各有一个导数零点；导数是二次多项式，所以这时恰有 2 个不同实零点。

反向推断不成立：导数零点只表示水平切线，并不一定是原函数零点；导数有两个实零点也不保证原函数有三个实零点。例如 x³−3x+10 的两个转折处函数值都为正，原函数只有一个实零点。
